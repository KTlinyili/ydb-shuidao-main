二、鲁棒性测试（抗干扰能力评估）

鲁棒性测试评估模型在不同干扰条件下的性能稳定性。测试方法：取验证集76张图片，分别施加不同程度的干扰，统计 Top-1 准确率变化。
干扰类型包括：光照变化、模糊、噪声、几何变换、压缩损失等。

测试方法说明：使用 Python + OpenCV 对验证集图片施加干扰，然后送入分类模型推理，统计准确率。 脚本位置：yolo_train/robust_test.py（待生成）。干扰强度参考 ImageNet-C 标准。

三、消融实验

消融实验通过逐个移除或替换模型的关键组件，分析各组件对最终性能的贡献。 基线模型为当前最佳配置：YOLOv8n-cls + ImageNet预训练 + 50 epochs + 224x224 + batch=16 + CPU。

实验编号 配置变化 移除/替换的组件 Top-1 准确率 训练损失 验证损失 参数量 模型大小 相对基线变化 状态
A0（基线） 完整模型 — 96.25% 0.087 0.450 1.44M 2.83MB — 实测
A1 无预训练权重 移除 ImageNet 预训练，随机初始化 — — — 1.44M 2.83MB — 待测
A2 无数据增强 关闭 train.transforms — — — 1.44M 2.83MB — 待测
A3 减少训练轮数 epochs: 50 → 20 91.25% 0.1995 0.3575 1.44M 2.83MB -5.00% 实测
A4 减少输入尺寸 imgsz: 224 → 128 — — — 1.44M 2.83MB — 待测
A5 增大批次大小 batch: 16 → 32 — — — 1.44M 2.83MB — 待测
A6 移除早停机制 patience: 15 → 关闭 92.50% 0.087 0.450 1.44M 2.83MB -3.75% 实测
A7 减少类别数 4类 → 3类（移除brown_spot） 85.00% 0.172 0.305 1.44M 2.83MB -11.25% 实测
A8 学习率调整 lr0: 0.001 → 0.01 — — — 1.44M 2.83MB — 待测
消融实验结论（部分）：
  • A3 vs A0：减少训练轮数（50→20）导致准确率下降5%，说明后期训练仍有提升空间
  • A6 vs A0：移除早停后最终准确率为92.5%（epoch 50），而早停保存的epoch 42为96.25%，验证了早停策略的有效性
  • A7 vs A0：3类模型（无brown_spot）准确率仅85%，4类模型96.25%，说明brown_spot类引入后模型整体判别能力提升
